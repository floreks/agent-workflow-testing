## A funny story

Once I tried to be extra productive and set my terminal prompt to show *everything*: git branch, exit code, Kubernetes context, battery level, the weather… the works.

It looked amazing until I ran a command that printed a long error message. The prompt was so “helpful” that it wrapped into the output, the output wrapped into the prompt, and I spent ten minutes debugging… my prompt.

Lesson learned: sometimes the best developer experience is fewer features and a little more silence.
